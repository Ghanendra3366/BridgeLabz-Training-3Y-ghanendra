Core principles

Responsive design, explained

Fluid Layouts

Use relative units so containers can expand and contract.

.page { width: min(90%, 1100px); }

Flexible Media

Images should fit their containers without breaking the layout.

img { max-width: 100%; height: auto; }

Breakpoints

Adjust the layout when the content needs a new shape.

@media (max-width: 600px) { ... }
